тот проект представляет собой полнофункциональную поисковую систему на базе Manticore Search, развернутую в контейнерной среде с использованием Docker Compose. Проект создан для демонстрации возможностей по созданию самостоятельного поискового решения с полным циклом обработки данных.
Ключевые возможности

🔍 Поисковая система
-------
Manticore Search в качестве поискового движка
Поддержка полнотекстового поиска
Расширенные возможности индексации и поиска
Гибкая конфигурация индексов

🐳 Контейнеризация
-------
Полная изоляция компонентов через Docker Compose
Простое развертывание и масштабирование
Единая среда для разработки и тестирования

📊 Управление данными
-------
API-интерфейс для заполнения индексов
Автоматическая обработка и индексация текстовых данных
Поддержка различных форматов входных данных

🧪 Тестирование
-------
Комплексные тесты для проверки корректности поиска
Автоматизированная проверка функциональности
Тесты производительности и нагрузочного тестирования

🌐 Веб-интерфейс
-------
Интерактивный интерфейс для проверки результатов поиска
Визуализация поисковых запросов и результатов
Удобный инструмент для отладки и тестирования
